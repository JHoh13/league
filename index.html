      Connect your ESPN league

      1. Install the ESPN client once. 
        pip install espn_api
      2. Run the export script from this chat. Public leagues need only the league ID and year. Private leagues also need your espn_s2 and SWID cookies. 
        python export_espn_league.py --league-id 123456 --year 2026 --espn-s2 "..." --swid "{...}"
      3. Click Load league.json above and choose the file it wrote. Standings, odds, scorers and injuries all refresh from your real league. Run the script again each week.
